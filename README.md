# Pathway — AI Career Advisor

A capstone project built for final-year students: get AI-matched career recommendations, honest CV feedback, a drafted cover letter, and practical career tips — all in one place.

## What it's built with

- **TanStack Start** (React 19 + Vite) — the app itself and its server-side routes
- **Firebase** — Authentication (email/password + Google) and Cloud Firestore for storing each user's profile, career matches, CV reviews, and letters
- **Google Gemini** — powers every AI feature, called only from a server route so the API key never reaches the browser
- **Tailwind CSS** — styling
